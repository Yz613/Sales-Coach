# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Sales Coach AI seriously. If you believe you have found a security vulnerability, please report it responsibly.

### How to Report
- **Do not open a public issue.**
- Please report security concerns through GitHub's Private Vulnerability Reporting feature under the **Security** tab of this repository.
- Include detailed steps to reproduce the issue, along with any relevant proof-of-concept code.

### What to Expect
- You will receive an acknowledgement of your report within 48 hours.
- We will provide updates on the status of our investigation and fix timeline.
- Once fixed, a security advisory will be published and credit will be given to the reporter.
